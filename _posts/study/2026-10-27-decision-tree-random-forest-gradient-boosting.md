오늘 공부한 의사결정나무, 랜덤포레스트, 그래디언트 부스팅은 이름만 보면 전부 나무 친척이다. 그런데 세 개를 한꺼번에 외우려니 자꾸 가지가 엉켰다. 지난번 시험에서 떨어진 뒤 다시 정리하는 중인데, 이번에는 이름보다 **나무를 만드는 순서와 결과를 합치는 방식**으로 구분해보기로 했다.

의사결정나무는 질문을 차례로 던져 데이터를 나눈다. 예를 들어 분류 문제에서 어떤 특성으로 나눌 때 그룹이 더 순수해지는지 살펴보고 분할을 고른다. 한 그루의 규칙을 따라가며 예측 과정을 읽기 쉬운 편이다. 다만 가지를 계속 늘리면 학습 데이터의 작은 차이까지 외워버릴 수 있다. `max_depth`나 `min_samples_leaf` 같은 제한이 필요한 이유다.

랜덤포레스트는 여러 나무를 **병렬로** 키운 뒤 결과를 모은다. 각 나무에 복원추출한 학습 표본을 주고, 분할할 때도 특성의 일부를 무작위로 살핀다. 나무들이 똑같은 실수를 되풀이할 가능성을 줄여 분산을 낮추려는 방식이다. 분류라면 각 나무의 예측을 투표처럼 모으고, 회귀라면 평균을 낸다. '숲이니까 무조건 정확하다'가 아니라, 단일 나무의 불안정함을 여러 나무로 누그러뜨린다고 기억해야겠다.

그래디언트 부스팅은 순서가 핵심이다. 앞에서 만든 모델의 예측을 보고, 다음 나무가 **손실을 줄이는 방향**으로 보완하도록 차례로 더한다. 여기서 내가 자꾸 '틀린 데이터만 다시 학습한다'고 뭉뚱그려 외웠는데 정확하지 않다. 손실 함수의 기울기에 맞춰 새 약한 학습기를 추가하는 방식이다. `learning_rate`는 새 나무의 기여 크기를 조절하고, 나무 수와 함께 조정해야 한다. 너무 오래 쌓으면 과적합도 살펴봐야 한다.

스스로 퀴즈를 냈다. **한 그루는 규칙을 따라간다. 숲은 독립적으로 만든 여러 나무를 모은다. 부스팅은 앞선 모델을 보완하며 순서대로 더한다.** 여기까지는 설명할 수 있겠다. 다음엔 같은 데이터로 세 모델의 학습 점수와 검증 점수를 비교해볼 생각이다. 이름 암기보다 과적합이 어느 쪽에서 나타나는지 직접 확인하는 편이 덜 헷갈릴 것 같다.
